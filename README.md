# General
This is OPPM repo for OpenComputers packed with personal programs.

# Development enviroment
Run `prepare-devenv.sh` to clone [AR2000AR/opencomputers-openos-definitions](https://github.com/AR2000AR/opencomputers-openos-definitions) and setup Lua by creating *.luarc.json* to use it. The script also applies the local patches, including AE2 component definitions (`me_controller`, `me_interface`, ME buses, cell workbench, interface terminal and `upgrade_me`).
